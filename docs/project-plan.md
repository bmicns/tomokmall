# 건축자재몰 프로젝트 계획서

> **서비스명**: bmicns-materials-mall
> **호스팅**: 닷홈 (PHP 8.4 + MySQL 8.0) → http://bmicns.dothome.co.kr
> **작성일**: 2026-06-17

---

## 1. 서비스 개요

B2C 건축자재 쇼핑몰. 고객이 용도를 자연어로 설명하면 AI가 설치 조건을 물어보고 최적 상품을 추천하는 방식으로 전문지식 없이도 자재를 구매할 수 있게 한다.

### 핵심 차별점

- **AI 대화형 상품 추천**: "하수관 위에 그레이팅 설치하고 싶어" → 설치장소·최대하중 질문 후 최적 상품 추천
- **공사 흐름 연계**: 유사품목 / 다음공정 자재 자동 연결
- **현장 단위 관리**: 프로젝트별 주문 이력·소모량 추적 및 유지보수 알림

---

## 2. 사용자 유형 (3가지)

| 구분 | 역할 | 주요 화면 |
|------|------|----------|
| **고객** (Customer) | 자재 검색·주문·결제·현장 관리 | 메인, 상품, AI상담, 장바구니, 주문, 마이페이지 |
| **직원** (Staff) | 고객 상담, 견적서 작성, 재고·업체 조회 | 상담목록, 견적 관리, 재고현황, 품목별 업체정보 (피그마 기준) |
| **관리자** (Admin) | 전체 회원·상품·주문·통계 관리 | 대시보드, 회원 관리, 상품 관리, 주문 관리, 통계 |

| 배관·설비 | PPR급수관, 스틸배관 |

### 데이터 수급 방법

1. **스크래핑**: dacity.kr (암거·배수 자재) — `scripts/scrape-dacity.mjs` 기존 구현
2. **Excel 임포트**: 공급업체 제공 파일 → DB 자동 변환 스크립트
3. **수동 입력**: 관리자 화면에서 직접 등록

## 4. 전체 고객 여정 (Customer Journey)

```
자연어 입력
    ↓
AI 상담 (설치환경·하중·예산 질문)
    ↓
상품 추천 (2~3개 비교)
    ↓
상품 선택 → 장바구니
    ↓
견적 요청 (직원 확인) 또는 바로 결제
    ↓
결제 (토스페이먼츠)
    ↓
주기적 관리
  ├─ A. 재주문 관리  : 이전 주문 기반 1클릭 재주문
  ├─ B. 유지보수 알림: 제품 수명 기반 교체 시기 알림
  └─ C. 현장별 관리  : 현장/프로젝트 단위 주문 이력·소모량 추적
```

## 7. DB 스키마 추가 필요 항목

기존: `categories`, `products`, `category_relations`, `estimates`, `estimate_items`

### 추가 필요 테이블

```sql
-- 회원 (고객/직원/관리자 통합)
users (id, role ENUM('customer','staff','admin'), name, email, password_hash, phone, created_at)

-- 주문
orders (id, user_id, total_price, status, payment_key, paid_at, created_at)
order_items (id, order_id, product_id, quantity, unit_price)

-- 현장/프로젝트 (주기적 관리 C)
sites (id, user_id, name, address, memo, created_at)
site_orders (site_id, order_id) -- 현장-주문 연결

-- AI 상담 세션
ai_sessions (id, user_id, session_key, messages JSON, result_product_ids JSON, created_at)

-- 유지보수 알림 (Post-MVP)
maintenance_alerts (id, user_id, product_id, order_id, alert_date, is_sent, created_at)
```

## 8. 화면 목록

### 고객용
- `/` — 메인 (AI 상담 입력 + 상품 목록)
- `/chat` — AI 대화형 상품 추천
- `/product/{id}` — 상품 상세
- `/cart` — 장바구니
- `/estimate` — 견적 요청
- `/checkout` — 결제
- `/mypage` — 주문 내역 / 재주문 / 현장 관리
- `/register`, `/login` — 회원가입·로그인

### 직원용
- `/staff/` — 견적 목록·상태 관리
- `/staff/estimate/{id}` — 견적 상세·작성
- `/staff/inventory` — 재고현황
- `/staff/vendors` — 품목별 업체정보

### 관리자용
- `/admin/` — 대시보드
- `/admin/users` — 회원 관리
- `/admin/products` — 상품 관리 (등록·수정·삭제·Excel 임포트)
- `/admin/orders` — 주문 관리
- `/admin/stats` — 통계

## 9. 개발 순서 (Sprint)
