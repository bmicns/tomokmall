# AI 상담 기능 기획서

> 작성일: 2026-06-19
> 버전: v2.0 (대장 논의 반영)

---

## 1. 개요

건설 자재 쇼핑몰의 핵심 차별화 기능. 자재를 잘 모르는 일반 사용자도, 빠르게 견적을 뽑아야 하는 업자도 각자에게 최적화된 방식으로 AI 상담을 이용할 수 있도록 두 가지 모드로 완전 분리 설계한다.

---

## 2. 진입 분기

```
AI 상담 시작 화면
      ↓
[일반]              [기업회원]
  ↓                     ↓
자연어 검색 모드    기업회원 로그인 확인
                    ↓ 로그인 O → 즉시견적 모드 (단가 표시)
                    ↓ 로그인 X → 기업회원 로그인 유도
```

---

## 3. 일반 모드 (자연어 검색)

### 3.1 신규 고객

1. 자연어 입력창 — 자유 텍스트로 필요한 자재 설명
   - 예) "차가 다니는 도로 옆에 물 빠지는 게 필요해요"
   - 예) "1200 암거 50개 필요한데요"
2. AI가 조건 파악 후 제품 추천 카드 2~3개 출력
3. 후속 질문도 자연어로 이어서 가능
   - 예) "암거랑 흄관 차이가 뭐예요?"
4. 제품 선택 → 수량 입력 → 견적 요청서로 연결

### 3.2 재구매 고객

로그인 후 이전 상담 이력에서 빠르게 재견적:

```
이전 상담 내역
┌────────────────────────────────────────┐
│ 2025.03.12  흄관 B형 외 2개           │
│ "도로 옆 배수로 공사"                 │
│             [다시 견적 요청] [상세]   │
├────────────────────────────────────────┤
│ 2024.11.05  암거 1200×1200 외 1개     │
│             [다시 견적 요청] [상세]   │
└────────────────────────────────────────┘
```

→ 클릭 시 이전 품목이 자동으로 담긴 견적 요청서 오픈

---

## 4. 기업회원 모드 (즉시 견적)

### 4.1 신규 견적

상단에서 제품/규격/수량 선택 → 확인 시 하단 목록에 누적 추가:

```
┌──────────────────────────────────────────┐
│  [제품군 ▼]  [규격 ▼]  [수량]  [추가]  │  ← 상단 선택 영역
└──────────────────────────────────────────┘

 ↓ 추가할 때마다 아래에 쌓임

┌────┬──────┬───────────┬────┬────────┬──────────┬───┐
│ No │ 제품 │    규격   │수량│  단가  │   소계   │   │
├────┼──────┼───────────┼────┼────────┼──────────┼───┤
│  1 │ 암거 │1200×1200  │ 50 │ 32,000 │1,600,000 │ × │
│  2 │ 흄관 │φ600 B형   │ 30 │ 18,500 │  555,000 │ × │
├────┴──────┴───────────┴────┴────────┼──────────┼───┤
│                              합계   │2,155,000 │   │
└─────────────────────────────────────┴──────────┴───┘
                              [견적 요청하기]
```

- **단가/합계는 기업회원 로그인 시에만 표시**
- 미로그인 시: "가격 확인은 기업회원 로그인 후 가능합니다"

### 4.2 재구매 고객

세 가지 빠른 진입 방법:

| 방법 | 설명 |
|------|------|
| 이전 견적서 재사용 | 목록에서 선택 → 수량만 수정 → 즉시 재요청 |
| 단골 품목 불러오기 | 자주 쓰는 제품/규격 저장 → 원클릭 로드 |
| 원클릭 재주문 | "지난번과 동일하게" → 최근 견적서 자동 로드 |

---

## 5. 견적 요청서 (공통)

두 모드 모두 동일한 견적 요청서로 합류. 선택한 품목은 자동으로 담긴 상태.

```
┌──────────────────────────────────────────┐
│              견적 요청서                  │
├──────────────────────────────────────────┤
│ 📦 신청 품목 (자동 포함)                 │
│   - 흄관 B형 φ600 × 30개               │
│   - 암거 1200×1200 × 50개             │
├──────────────────────────────────────────┤
│ 🚚 배송 요청 일시                        │
│   [날짜 선택 📅]  [오전/오후 시간 선택] │
│   □ 날짜 미정 (담당자와 협의)          │
├──────────────────────────────────────────┤
│ 👤 신청인 정보                           │
│   담당자명 / 연락처 / 회사명 / 이메일   │
├──────────────────────────────────────────┤
│              [견적 요청하기]             │
└──────────────────────────────────────────┘
```

---

## 6. 재구매 알림 (마이페이지 연동)

### 6.1 납품 완료 알림

납품 완료 시 문자/이메일 발송 → 마이페이지 알림 설정 유도:

```
"납품이 완료됐습니다. 감사합니다.
 마이페이지에서 재구매 알림을 설정하시면
 시기가 되면 미리 알려드릴게요."

 [마이페이지 바로가기]
```

### 6.2 마이페이지 — 납품 이력 + 알림 설정

```
내 납품 이력
┌────────────────────────────────────────────────┐
│ 2025.03.12  흄관 B형 φ600 × 30개              │
│             암거 1200×1200 × 50개             │
│ 알림 설정: [1년 후 ▼]              [저장]     │
├────────────────────────────────────────────────┤
│ 2024.11.05  그레이팅 외 2개                    │
│ 알림 설정: 미설정            [설정하기]        │
└────────────────────────────────────────────────┘
```

알림 시기 옵션: `1년 후` / `2~3년 후` / `5년 이상` / `잘 모르겠어요`

시기 도래 시 → 문자/이메일 알림 + 재견적 바로가기 링크 포함

## 7. 전체 플로우 요약

```
AI 상담
├── 일반
│   ├── 신규       → 자연어 검색 → AI 추천 카드 → 견적 요청서
│   └── 재구매     → 이전 상담 이력 → 재견적
└── 기업회원
    ├── 신규       → 즉시견적 (선택 누적 + 단가 실시간 표시)
    └── 재구매     → 단골품목 / 이전견적서 / 원클릭 재주문

견적 요청서 (공통)
  → 품목 자동 포함 + 배송 요청 일시 선택 + 신청인 정보
  → 견적 요청 완료

납품 완료 후
  → 마이페이지 알림 설정 유도
  → 납품 이력별 재구매 시기 설정
  → 시기 도래 시 알림 → 재견적 연결
```

## 8. 기대 효과

| 효과 | 내용 |
|------|------|
| 진입 장벽 제거 | 전문 용어 몰라도 자연어로 자재 찾기 가능 |
| 업자 업무 효율 | 전화 없이 현장에서 즉시 금액 파악 + 견적 요청 |
| 재구매 유도 | 이력 기반 원클릭 재주문 + 알림으로 자연스러운 재방문 |
| 차별화 | 단순 폼 방식 대비 압도적인 UX 경험 |
