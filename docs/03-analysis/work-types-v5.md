# 작업 유형 v5 — 상황 분류와 추천 자재 근거 (메인 '어떤 작업에 사용할 예정인가요?')

- 작성: 2026-11-05 · 적용 코드: `app/work_types.php` `work_types()` (v4 `docs/03-analysis/work-types-v4.md` 를 대체)
- 대상 화면: 비로그인·개인회원 메인의 작업 카드 12개와 펼침 패널, 작업별 상품 목록(`products.php?category=ID&work=키`)
- 목적: v4 는 모든 선정이 "일반적인 시공 관행에 근거한 판단"이었다. v5 는 **법령·국가건설기준·정부 지침·공공기관 자료**를 찾아 자재마다 근거와 근거 수준을 붙이고, 근거가 약하거나 상황에 맞지 않는 자재를 바꿨다.
- 범위: 설정(코드)만 변경. **운영 DB 변경 없음, 가격 관련 데이터·로직 변경 없음, 배포 없음.**

## 1. 조사 방법과 한계 (먼저 읽어 주세요)

1. **운영 DB 확인(읽기 전용, 2026-11-05)**: 원격 관리 API `db query`(SELECT)로 카테고리 245개의 사용 여부·판매중 상품 수, 카테고리별 대표 상품 2개의 이름·규격만 조회했다(가격 컬럼 조회 없음). 선정한 자재 113건(중복 포함)은 모두 **사용 중(is_active=1)이고 판매중 상품이 1개 이상**이며 이름이 DB 와 같다.
2. **외부 근거 조사**: 서브 에이전트 3개가 배수 / 포장·경계·주차·조경 / 옹벽·하천·담장·지중설비로 나누어 조사했다.
3. **한계와 원문 대조(2026-11-05 갱신)**: v5 작성 당시에는 네트워크 정책 때문에 원문을 열지 못해 모든 근거가 검색 요약·2차 사본이었다. 2026-11-05 네트워크 허용 후 **국가법령정보센터(law.go.kr) 현행 법령 본문·별표 PDF, 국가건설기준센터(kcsc.re.kr) 현행판 본문, law.go.kr 행정규칙(국토교통부 예규·고시)**으로 3장의 근거를 대조했다(4-0 표).
   - 표의 수준 칸에 **'원문 확인'**이 있는 항목은 이 원문에서 조문·수치·문구를 직접 확인한 것이다. 판본은 4-0 표에 적었다.
   - K3 「도로 배수시설 설계 및 관리지침」·K8 「하천 설계기준·해설」·P10·P16 은 건설기술정보시스템(codil.or.kr) 원문 PDF 로 대조했다(2026-11-05 2차). 처음에는 codil 서버가 **중간 인증서를 보내지 않아** TLS 검증이 실패했다. 인증서에 적힌 발급기관 주소(AIA)에서 중간 인증서(TuringSign RSA Secure CA 2)를 받아 신뢰 루트(OISTE WISeKey Global Root GB CA)까지 검증된 것을 확인하고, 그 인증서를 더한 CA 파일로 **검증을 켠 채** 접속했다(검증 끄기 없음).
   - 아직 원문을 못 본 출처: 대조 범위 밖이었던 L14·K15·K16·K18~K20 과 P·R 대부분(P10·P16 제외). 이 출처의 문구는 v5 수준을 그대로 두었다.
   - 대조 결과 **선정을 바꿔야 할 만큼 근거가 무너진 자재는 없었다**(바뀐 것은 보조 수치·문구·조문 위치). 자재 목록 변경은 사용자 결정에 따른 정원 1건(104 → 157)뿐이다. 화면에는 출처를 표시하지 않고, 법령 주의 안내 1건(옹벽 배수관 재질)만 표시한다.
4. **추론 표시**: 기준에 적힌 시설을 쇼핑몰 카테고리에 짝지은 부분(예: "U형 콘크리트 측구" → 측구수로관B형)은 출처에 직접 적힌 내용이 아니다. 이런 부분은 표에 **(추론)**으로 표시했다.
