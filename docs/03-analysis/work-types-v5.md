# 작업 유형 v5 — 상황 분류와 추천 자재 근거 (메인 '어떤 작업에 사용할 예정인가요?')

- 작성: 2026-11-05 · 적용 코드: `app/work_types.php` `work_types()` (v4 `docs/03-analysis/work-types-v4.md` 를 대체)
- 대상 화면: 비로그인·개인회원 메인의 작업 카드 12개와 펼침 패널, 작업별 상품 목록(`products.php?category=ID&work=키`)
- 목적: v4 는 모든 선정이 "일반적인 시공 관행에 근거한 판단"이었다. v5 는 **법령·국가건설기준·정부 지침·공공기관 자료**를 찾아 자재마다 근거와 근거 수준을 붙이고, 근거가 약하거나 상황에 맞지 않는 자재를 바꿨다.
- 범위: 설정(코드)만 변경. **운영 DB 변경 없음, 가격 관련 데이터·로직 변경 없음, 배포 없음.**

## 1. 조사 방법과 한계 (먼저 읽어 주세요)

1. **운영 DB 확인(읽기 전용, 2026-11-05)**: 원격 관리 API `db query`(SELECT)로 카테고리 245개의 사용 여부·판매중 상품 수, 카테고리별 대표 상품 2개의 이름·규격만 조회했다(가격 컬럼 조회 없음). 선정한 자재 113건(중복 포함)은 모두 **사용 중(is_active=1)이고 판매중 상품이 1개 이상**이며 이름이 DB 와 같다.
2. **외부 근거 조사**: 서브 에이전트 3개가 배수 / 포장·경계·주차·조경 / 옹벽·하천·담장·지중설비로 나누어 조사했다.
3. **한계 — 원문 미열람**: 이 클라우드 세션의 네트워크 정책이 `www.law.go.kr`·`www.kcsc.re.kr`·`www.molit.go.kr`·`www.codil.or.kr`·`korea.legal` 등을 차단해 **원문 PDF·조문을 직접 열지 못했다.** 아래 근거는 모두 **웹 검색 결과의 요약·발췌문**이다. 상당수는 게시판·블로그에 올라온 기준 사본을 거친 2차 확인이다. 조문 번호·수치는 현행본과 대조하지 못했다.
   → **화면에 출처를 게시하거나 영업 자료에 인용하기 전에** 4장 출처를 원문(국가법령정보센터, 국가건설기준센터)과 대조해야 한다. 현재 화면에는 출처를 표시하지 않는다(설정과 문서에만 둠).
4. **추론 표시**: 기준에 적힌 시설을 쇼핑몰 카테고리에 짝지은 부분(예: "U형 콘크리트 측구" → 측구수로관B형)은 출처에 직접 적힌 내용이 아니다. 이런 부분은 표에 **(추론)**으로 표시했다.

**분류 변경 이유**
- **'담장·기초 콘크리트 공사'(fence) → '정원·담장 꾸미기'(garden)로 통합**: 쇼핑몰에 기초 콘크리트 자재(레미콘·시멘트·철근)가 없다(ID 1 '철근/시멘트'는 임시 상품 1개). 관련 카테고리는 블록·벽돌 4개뿐이고, PHC파일(57)은 지름 500mm·길이 5~14m 항타 말뚝이라 개인 공사에 맞지 않는다. 블록 담장은 개인 마당 공사에서 정원과 함께 하는 일이 많아 garden 에 합쳤다.
  - 흙을 받치는 담은 법령상 옹벽과 같이 다뤄지므로 retaining 이 담당한다(건축법 시행령 제118조 [L6]).
  - `products.php?work=fence` 링크는 일반 카테고리 목록으로 표시된다(오류 없음). 사이트 안에서 이 링크를 쓰는 곳은 없다.
- **'논밭 수로 정비'(farm) 신설**: 배수·옹벽 조사 2건이 공통으로 권했다. 농가는 마당 배수와 고객층·자재가 다르다(U형 플륨관·농로 횡단 수로·생태탈출로).
  - 2023년 야생생물법 시행규칙 개정(동물 추락 우려 인공구조물에 탈출시설)과 환경부 수로 탈출시설 지침·국립생태원 연구가 U형 벤치플륨관 수로를 대상으로 한다 [L15][P4][R1].
- 작업 키(URL)는 기존 11개를 그대로 두어 기존 링크·검증 스크립트가 깨지지 않게 했다.
