## 1. 해결한 문제와 실제 수정

### A. 모호한·불완전한 질문 (사용자 지정 8문장)

서버는 고객 말이 모호하면 **해석을 정하지 않고** GPT 에 확인 질문 근거를 준다(검색 결과의 `clarify` + 그 턴의 시스템 안내 '이번 고객 말에서 확인이 필요한 점'). 분명한 조건만 유지·변경한다.

| 고객 말 | 수정 전 | 수정 후 |
|---|---|---|
| ① 길이 10m짜리 그레이팅 찾아줘 | 서버 판단 없음 — GPT 가 10m 를 제품 길이(→ 0건)나 설치 길이로 추측 | 1개 길이로 보기엔 너무 김(관 아닌 품목 3m 초과) → 길이 조건을 넣지 않고(GPT 가 넣었으면 뺌) 후보만, 수량 없음, '설치 구간 총 10m 인지' 확인 |
| ② 폭은 그대로 하고 길이만 두 배로 | 서버 판단 없음 | 앞 조건이 제품 길이 하나면 그 값 × 2(1m → 2m), 제품 길이·설치 길이가 둘 다 있거나 없으면 모호 → 앞 조건 유지(GPT 가 바꾼 값 되돌림) + '어느 길이를' 확인 |
| ③ 아까 그 제품 말고 더 튼튼한 거 | 제외만 — 같은 등급 제품을 '튼튼하다'고 말할 수 있음 | 앞 제품보다 **하중 등급이 높다고 확인된**(상품명 등급·규격 용도 표기) 제품만, 카드에 load_grade·근거. 앞 제품 등급을 모르면 비교하지 않고 이유·통행 조건 확인 |
| ④ 차가 다니는데 이 제품 써도 돼? | 새 검색 + 재확인 | 지금 표 제품만 새 조건(car)으로 판정(only_ids) — 보행자용은 표에서 빠지고 '하중 부족' 이유 |
| ⑤ 500짜리 수로관 20m 필요해 | GPT 가 500 을 폭으로 넣으면 그대로 | 치수 이름 없는 숫자 → 폭으로 단정하지 않음(spec_mm 500 — 어느 자리든), '20m 필요' = 설치 길이, 어느 치수인지 확인 |
| ⑥ 앞에서 추천한 것 중 가장 저렴한 제품으로 | 수량이 없으면 '가장 저렴' 표시 없음, 단위가 달라도 GPT 가 단가로 고를 수 있음 | 직전 표 안내: 예상 자재비(같은 설치 길이)가 있으면 그 기준, 없으면 같은 판매 단위일 때만 단가 기준, 개·M 이 섞이면 '정할 수 없다 — 설치 길이를 물어라' |
| ⑦ 폭 400으로 바꾸고 나머지는 그대로 | (3차에서 해결) | 폭만 400, 제품 길이·설치 길이·통행 유지 — 모호하지 않으므로 확인 질문 근거 없음 |
| ⑧ 이 제품 대신 비슷한 규격의 다른 제품 | 제외만, 규격 기준 없음 | 앞 표 제품의 **구조화된 확인 치수**(dim_w·dim_l, 숫자 자리 추측 아님)가 모두 같으면 그 폭·길이, 제품마다 다르면 '어느 제품 기준인지' 확인 |

- '폭 400 길이 1m'처럼 폭과 붙여 말한 3m 이하 길이는 제품 크기로 본다(모호하지 않음). '폭은 500mm이고 길이는 10m'·'10미터길이에'는 어느 길이인지 말에 없음 → GPT 해석(대개 설치 길이)은 두고 그 기준을 밝혀 확인하게 한다(1차 운영 상담 흐름 그대로 통과).

### B. 추천 정확도

- **제외 조건 유지**: '다른 제품'으로 나온 표는 고객이 뺀 제품 id 를 표의 검색 조건(cond)에 남기고, 같은 품목의 다음 검색(폭 변경 등)에서도 계속 뺀다. 품목이 바뀌면(그레이팅 → 수로관) 가져가지 않는다.
- **버그 수정 — 넓은 검색어의 '다른 제품'**: '그레이팅'처럼 넓은 검색어는 위 40행이 모두 뺄 상품명의 다른 규격이라 '다른 제품이 없습니다'로 잘못 끝났다(실제로는 다른 그레이팅 다수). 제외할 제품이 있으면 300행까지 조회.
- **회원별 가격 비교**: '더 저렴한' 기준·결과 모두 지금 로그인 등급 단가(비회원 판매가·개인·기업 회원가)로 같은 설치 길이의 예상 자재비를 비교함을 MOCK 상품으로 확인(가격 계산·DB 변경 없음).
- 하중(3차 유지·보강 검증): 보도용은 차량 통행에서 빠짐, '차도용'은 대형차·중장비(덤프·레미콘 포함)에 확인 필요, 근거 없는 제품은 '하중 확인 필요'.
- 규격 미확인 제품: 확인된 제품 뒤, '규격 확인 필요' 표기(실제 데이터 '덮개 폭 300'으로 순서·표기 확인).

2. **덮개 — 조화맨홀 원형 4·각종주철 9(중요도 낮음)** — 대상: 상품별 치수 칸(직경 `dim_d`·두께 `dim_t`·높이 `dim_h`). 근거: 규격 글자의 D·Ø·T·h 표기 + 머리글 '외경기준'. 카테고리 이름표 하나로는 안 되므로(사각·수공·계량기뚜껑 혼재) 상품별 채움 방식 결정이 먼저 필요(E-2 결정 재검토는 사용자 판단). 효과: 화면 치수 표기·직경 검색 근거(지금 AI 폭·길이 검색엔 영향 적음).
3. **석재 두께(중요도 낮음)** — 대상: 상품별 `dim_t`(T 표기 11개 — 화산석 7·판석 3·사비석 1). 근거: 규격 글자의 T. 효과: '두께 30T 판석' 같은 두께 검색 근거. 면 치수(가로·세로)는 확인 불가로 둔다.

## 5. 남은 점

1. (중) 실제 GPT-4o 미검증 — 확인 질문을 실제로 하는지, 새 인자를 쓰는지. 위 3장 절차로 확인 필요.
