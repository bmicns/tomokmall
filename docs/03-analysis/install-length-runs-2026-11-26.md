# AI 상담 설치 길이 질문·줄별 수량·질문 방식 (2026-11-26, 사용자 결정 B안)

## 1. 문제 (지금 구조 분석)
- 질문이 "설치 길이(m)" 하나뿐이고 도구도 설치 길이를 숫자 하나(`length_m`, 총 길이)로만 받았다. 고객이 "10m"라고 답하면 한 줄인지 합계인지 알 수 없었다.
- 빠른 상담 `quick_install_amount()` 가 "10m씩 2줄"·"10m 2줄"·"양쪽 20m씩"을 **10m·20m 한 줄로 읽어 수량이 절반**이었고, "10m, 15m"는 읽지 못했다.
- 경계석은 보도블록과 같은 필수 항목 묶음이라 **면적(㎡)을 물었고**, 흄관은 상담 품목 감지(`rag_detect_category`)에서 관류로 잡히지 않아 **설치 길이를 묻지 않았다**('기타 자재').
- 수량은 "합계 ÷ 1개 길이"를 한 번만 올림 — 여러 줄이면 줄 끝 자투리 때문에 실제보다 적게 나왔다(2m 수로관 7m×3줄: 11본 → 실제 12본).

## 2. 결정 (2026-11-26 마스터님 — B안)
문구 + 서버가 줄 구성 읽기 + 줄마다 수량 계산. 두 상담(기존 AI 상담 `/chat.php`·우측 하단 빠른 상담) 모두, 화면·대화 흐름은 그대로, 가격 데이터·단가·마진율·가격 계산식은 그대로.

## 3. 구현
| 부분 | 파일 | 내용 |
|---|---|---|
| 줄 구성 읽기 | `app/install_runs.php` `install_runs_parse` | "10m씩 2줄"·"10m 2줄"·"2줄 각 10m"·"10m, 15m"·"10m 한 줄, 15m 한 줄"·"10m 2줄, 5m 1줄"·"양쪽 20m씩"·"10m, 15m 두 줄" → 줄마다 길이. "총 30m 3줄"·"30m를 3줄로"·"두 줄로 20m" → **줄마다 길이 모름**(나누지 않음). 띄어쓰기만("10m 30m")·폭·높이·1개 길이·규격 표기 숫자는 읽지 않음 |
| 대화 기준 | `install_runs_from_messages` | 설치 길이를 말한 마지막 고객 말 기준(나중에 "총 20m"처럼 한 줄 길이로 고쳐 말하면 풀림) |
| 도구 입력 | `ai_tools.php` `search_products`·`update_cart` | 새 칸 `runs_m`(줄마다 길이)·`run_count`(줄 수만 알 때). `length_m` = 합계. `ai_tool_dispatch` 가 도구 한 번 실행 동안만 줄 구성을 수량 계산에 넘기고 비움 |
| 서버 바로잡기 | `rag.php` `rag_apply_runs` | GPT 가 한 줄 길이(10)나 합계(20)만 넘겨도 고객 말대로 `runs_m`. 같은 현장 다른 자재(수로관 본체+그레이팅)는 같은 길이를 넘기면 같은 줄 구성. 다른 길이·길이 없는 다른 품목(맨홀)은 건드리지 않음 |
| 빠른 상담 | `quick_match.php` `quick_install_amount`, `tool_quick_install_qty` | "10m씩 2줄"만 말해도 20개로 맞추고 "설치 길이 10m×2줄(총 20m)이면 … 20개 정도" 한 줄 |
| 수량 | `install_runs_piece_qty` (← `ai_estimate_quantity`) | 아래 4장 |
| 줄 기준 표시 | 검색 표·`update_cart` 결과 `run_basis` | 길이만 답함 → "한 줄 20m 기준"(되묻지 않음), 여러 줄 → "10m×2줄(총 20m)". 줄마다 길이 모름 + 줄마다 올림 자재 → `run_note`(줄마다 길이를 한 번만 물음) |
| 질문 방식 | `rag.php` `RAG_QUESTION_STYLE_PROMPT` | 5장 — 두 상담 프롬프트 공통 구역 |
| 질문 바로잡기 | `rag.php` | 경계석 필수 항목 분리(설치 장소·차량 + 설치 길이), 블록 뒤 경계석 질문에 길이 예시, 관류 묶음에 흄관·이중벽관·파형강관, `rag_detect_category` 관류에 흄관 등, 경계석만 상담할 때 면적 질문 → 설치 길이(`rag_is_curb_only`) |
| 스위치 | `app/features.php` `FEATURE_AI_INSTALL_RUNS` | false = 반영 전과 같음(프롬프트는 `app/install_runs_legacy.php` 로 글자까지 되돌림, 도구 칸 없음, 한 줄 합계 계산) |

## 4. 수량 규칙 (자재별 시공 특성)
| 자재 | 계산 | 이유 |
|---|---|---|
| 개·본 단위 길이 자재(콘크리트 수로관·측구·흄관·경계석·그레이팅·트렌치 등) | **줄마다 올림 후 합계** (10m·15m, 2m 본 → 5 + 8 = 13본) | 줄 끝에서 잘라 쓰고 자투리를 다른 줄에 잇지 않음(이음부·소켓·하중 문제) |
| PE·PVC 관류(이중벽관·다중벽관·유공관·주름관·PVC관·PE관) | 합계 ÷ 1개 길이 | 잘라서 이음관으로 이어 써 자투리를 다른 줄에 씀 — **가안(마스터님 확인 대기)**: 상품명·분류 이름 `INSTALL_RUNS_REUSE_RE` |
| 미터(M) 단위 판매 | 합계 그대로 | 필요한 길이만큼 판매 |
| ㎡ 단위·면적 | 줄 구성과 관계없음 | 면적 계산 그대로 |
| 줄마다 길이 모름("총 30m 3줄") | 합계로 계산 + 근거에 "줄마다 길이 모름" | 균등 분배 금지(사용자 요청). 줄마다 올림 자재만 줄마다 길이를 한 번 물음 |

- 예상 자재비 = 단가 × 수량(기존 식). 견적 목록·견적 카드 금액 = 표시 단가 × 바뀐 수량(`quote_draft_build` 그대로) — `tests/install_runs.test.php` 에서 로컬 테스트 DB 로 확인.
- 한 줄이면 계산·근거 문구가 반영 전과 같다(`21m ÷ 2m = 11본`).

## 5. 질문 방식 (공통 대화 지침 — 특정 자재가 아니라 모든 질문)
1. 안내형 질문("~을 알려 주세요"), "~알고 계신가요?"·"~알 수 있을까요?" 같은 돌려 묻기 금지
2. 무엇을 답하면 되는지 분명히 — 헷갈리는 값(치수·길이·면적·관경·수량)은 단위와 짧은 예시를 질문에 함께
3. 필요한 정보는 한 메시지에 한 번에(2~3개), 추천에 필요 없는 것은 묻지 않음
4. 이미 말한 정보(같은 현장 다른 자재 포함)는 다시 묻지 않음
5. 정확한 규격을 모르면 대략값·현장 설명·가장 많이 쓰는 규격으로 먼저 보여 주기로 이어 감
6. 친절·전문적, 공문체·같은 인사 반복 금지
- 설치 길이 질문 문장(길이 자재 공통): "설치 길이(m)를 알려 주세요. 여러 줄을 설치하는 경우 각 줄의 길이를 알려 주세요. (예: 10m씩 2줄 또는 10m, 15m)" — 길이·개수를 모를 때만.
- 품목별 [필수 확인 항목]은 "무엇을" 물을지만, "어떻게" 묻는지는 이 구역 한 곳에서 관리(`RAG_QUESTION_STYLE_PROMPT`).
