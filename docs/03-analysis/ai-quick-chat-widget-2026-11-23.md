## 1. 화면
- 고객 화면(공통 레이아웃 `render_footer`) 우측 하단 'AI 빠른 견적' 버튼 → 380px 창(모바일 640px 이하 전체 화면). AI 상담 화면(`/chat.php`)에는 나오지 않는다.
- 창: 머리(제목·'관리자·직원 시험 중'·새 대화·닫기), 대화(예시 질문 2개), 입력 200자(글자 수 표시, Enter 보내기·Shift+Enter 줄바꿈), 안내 'AI 답변에는 오류가 있을 수 있습니다…'.
- 담으면 답 아래 견적 표: 품목마다 상품명·규격·단가·수량·소계·상품보기 → 상품 합계·운반비(지역)·부가세·총합계 → [견적 요청하기]. 값은 견적 카드(A8, `app/quote_draft.php`)와 같은 서버 계산. 운반비를 모르면 0원이 아니라 '알려 주시면 계산'.
- 대화는 이 탭 동안(sessionStorage) 페이지를 옮겨도 이어지고, 서버에도 저장(`ai_sessions`). 견적서(장바구니)는 사이트 공통.

## 2. 대화 방식 (케이토목식)
- `rag_process(..., 'quick')` → 시스템 프롬프트 맨 끝에 `RAG_QUICK_STYLE_PROMPT`: 3~5줄·200자 안팎, 자재·수량을 말하면 되묻지 않고 찾아 **1개를 바로 담음**('우선 가장 일반적인 규격으로 담아 드렸습니다'), 수량 근거 한 줄, 금액은 글로 쓰지 않음(표가 보여 줌), 지역 모르면 한 줄로 물음.
- 그대로인 것: 차량·하중·두께·공공도로 규칙, 안전 필수 조건이 없으면 그 하나만 묻기, 가격·수량·운임 계산, 상품 데이터.
- 케이토목과 다르게 한 것: 운반비 0원 대신 예상 운임(또는 '별도'), 확인이 꼭 필요한 조건은 한 줄로 묻기.
- 견적서 사진 올리기: 7장(A10). 이전 대화 목록: 미구현.

## 3. 비교 방법

## 7. 견적서 사진 첨부 (A10, 2026-11-24 사용자 결정 '안내 후 그대로 보내기')
- 창의 [견적서 사진 첨부] → 사진 고르기(jpg·png, 10MB) → 미리보기 + 안내 '이름·전화번호는 가리고 올려 주세요. 사진은 AI 분석에 쓰이고 저장하지 않습니다' + 동의 체크 → [사진 보내기](체크 전에는 못 누름).
- 브라우저: 긴 변 1600px JPEG 로 줄여 보냄(흰 바탕). 사진은 sessionStorage 에도 남기지 않고, '나' 말풍선에는 읽은 품목 글만.
- 서버 `POST /api/chat/quick.php {action:'photo', sid, image, consent:true}`(`app/quick_photo.php`):
  1. 스위치 `FEATURE_AI_QUICK_PHOTO`·동의(`consent === true`) 확인 — 없으면 OpenAI 를 부르지 않고 거부
  2. 사진 확인: base64·10MB·실제 이미지 형식 jpg/png(`getimagesizefromstring`)
  3. OpenAI gpt-4o 1회(JSON): 품명·규격·수량·단위·애매함만, 사람 이름·상호·전화·주소·이메일·사업자번호·계좌·단가·금액은 적지 않게 지시
  4. 돌아온 글에서 전화·이메일·사업자번호 모양을 한 번 더 지우고 '[견적서 사진에서 읽은 품목]' + 번호 줄(최대 10줄)로 만듦
  5. 이 글을 질문으로 보통 질문과 같은 흐름(`rag_process` 'quick') — 줄마다 찾아 그 수량으로 담고, 못 찾거나 애매한 줄은 답 끝 '확인 필요:'
- 저장: 사진·OpenAI 원문은 저장·로그하지 않음(요청 메모리에서만). 대화(`ai_sessions`)·상담 로그(`chat_logs`)에는 읽은 품목 글만.
- 사진 속 단가·금액은 쓰지 않는다(가격은 우리 상품 가격 — P0-4).
- 검증: `tests/quick_chat.test.php` 42 통과(순수 함수 16 + 동의 없음·이미지 아님 거부(OpenAI 호출 없음)·목업 비전 → 담기 → 견적 표·비전 요청 내용·상담 요청에 사진 없음·로그에 사진·전화번호 없음). 화면 1280px·360px(목업 응답): 동의 전 보내기 비활성, JPEG 전송, sessionStorage 에 사진 없음, 가로 스크롤 없음.

## 13. 제품 길이(L)는 항상 m, 기록 지우기 글자 모양 (2026-11-26, 사용자 요청)
