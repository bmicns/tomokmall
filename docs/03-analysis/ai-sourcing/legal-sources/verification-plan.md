- 「도로의 구조·시설 기준에 관한 규칙」 제29조제1항(포장): "적절한 재료와 두께로 포장" — **두께 수치 없음**(법제처 원문 미러, 국토교통부령 제1588호·2026-06-03 시행). 80T 의 법적 근거가 아니며 상담 근거로 연결하지 않음(V04 비활성).
- 「도로와 다른 시설의 연결에 관한 규칙」 제7조: 변속차로 등은 접속 도로 포장과 같은 강도의 두께·재료로 포장 — 역시 블록 두께 수치 없음.
- 남은 확인 대상: KDS 44 50 25 본문(차도용 블록포장설계), KDS 34 60 10 현행 여부, KS F 4419 두께 종류.

## 4. 80T 관련 상담 문구 — 현재 상태 유지 (사용자 결정 2026-10-27)

다음 문구는 **변경하지 않는다**(`app/rag.php`, 운영 사내 기준 문서 5번, 상담 가이드):

- 법적·기술 근거 검증은 3장의 별도 조사 항목으로 계속한다(결과는 기록·보고만, 문구 변경은 사용자 결정).
