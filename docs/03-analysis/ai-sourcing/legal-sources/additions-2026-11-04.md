# 법령 근거 보완 2차 — V28~V35 (2026-11-04)

목표: 자재를 모르는 고객이 **공사 자체의 법적 조건(신고·허가·기준)**을 물어도 출처 있는 답을 받게 해서, 상담을 믿고 구매까지 이어지게 한다.
1차(V01~V27)는 보도블록·주차·배수·하수도·점자블록 위주였고, 메인 화면 작업 12개 중 **옹벽·담장·하천·흙 돋우기·도로 앞 공사·KS 표시** 질문에는 근거가 없었다.

## 3. 확인 방법 (추측 없음)

1. **원문**: 법제처 국가법령정보 OPEN API 원문 미러(GitHub `legalize-kr/legalize-kr`·`admrule-kr`)에서 조문을 직접 열람(이 클라우드 환경은 law.go.kr 차단, 미러는 접속 가능).
2. **현행판 선택**: 미러 최신본에는 **아직 시행 전인 개정판**이 섞인다(건축법·국토계획법·도로법·소하천정비법·산업표준화법). 미러 git 이력에서 시행일 ≤ 2026-11-04 인 판을 골라 기준값을 만들고, 인용 조문이 시행 예정판과 같은지 대조했다.
   - 같음: 건축법 제40·83조, 도로법 제52·61조, 소하천정비법 제14조, 산업표준화법 제24조 등
   - 다름(인용하지 않는 항만): 국토계획법 제56조제3항(2027-05-13 시행, 임도법 이름 변경), 산업표준화법 제15조제1항(2027-03-16 시행, 인증 대상자 문구) → `api_targets.json` 의 `pending` 에 기록
3. **감시 등록**: `api_targets.json` 에 문서 11건(감시 조문 14개) 추가, `mirror_recheck.php` 경로 추가. 2026-11-04 재실행 결과 — 기존 16개 문서는 10-27 기준과 모두 같음(바뀐 근거 없음), 새 문서는 기대대로(same 6 · pending 5).
4. **공식 API 대조는 아직** — 사용자 PC 에서 `law_api_sync.php` 실행이 필요(아래 5장). 그 전까지 운영 활성화 SQL 에서 자동 제외(`PROD_NEEDS_OFFICIAL_CHECK`).
