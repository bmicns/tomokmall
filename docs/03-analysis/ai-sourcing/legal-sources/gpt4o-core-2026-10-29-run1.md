# 실제 LLM 상담 시나리오 결과 (핵심 3개, 2026-10-29 02:40, 모델 gpt-4o, V21·V22 실행 중 활성)

## 1. 기대 public_road · 판정 public_road · 자동 점검 확인 필요(추천 상품도 '적합 상품 없음' 안내도 없음 — 100mm 검색을 했는지 원문 확인)

- 고객: 시청에서 발주한 도로 공사인데 차도에 블록 깔려면 두께 몇 mm 써야 해요? → 차도 면적은 50㎡ 정도예요. 인터로킹 블록으로 찾아 주세요
- 확인할 점: 100mm 이상 안내 + KDS/KCS 44 50 25 출처, 80T 비권장, 100mm 제품만(없으면 적합 상품 없음 안내 — 80T·60T 대체 추천 금지, 설계도서 확인·별도 견적)
- 인용 근거: 없음
- 추천 상품(마지막 턴): 없음

```
차도용 블록포장 설계 기준에 맞는 100mm 두께의 블록을 찾아 드릴게요. 잠시만 기다려 주세요.
```

## 2. 기대 public_sidewalk · 판정 public_sidewalk · 자동 점검 확인 필요(추천 상품도 '적합 상품 없음' 안내도 없음 — 80mm 검색을 했는지 원문 확인)

- 고객: 가게 앞 인도를 차가 가로질러 들어오는데 인도 블록 두께는요? → 승용차만 들어오고 면적은 30㎡예요
- 확인할 점: 보도 지침 구분 Ⅱ(4t 이하) 80mm 이상 + 출처, 80T 제품
- 인용 근거: 없음
- 추천 상품(마지막 턴): 없음

```
승용차가 올라가는 곳이라면 두께 80mm 이상의 블록을 사용하는 것이 좋습니다. 설치 면적이 30㎡이므로, 아래의 블록 종류 중에서 선택하실 수 있습니다:

- 인터로킹 블록: 차량 진입 시 매우 튼튼하며 디자인이 다양합니다. / 다소 복잡한 패턴을 선택하면 시공비가 증가할 수 있습니다.
- 중하중 보차도블록: 차량 하중을 잘 견딥니다. / 주차장이 아닌 곳에서는 무거워 보일 수 있습니다.

이제 원하시는 블록 종류에 대한 제품을 찾기 위해 추가 정보가 필요하신가요?
```

## 3. 기대 private · 판정 private · 자동 점검 통과

- 고객: 집 앞 마당에 차 두 대 주차할 건데 블록 두께 몇 T? → 마당은 6m × 5m 예요
- 확인할 점: 기존 80T 안내, 공공도로 출처 없음, 80T 제품
- 인용 근거: 없음
- 추천 상품(마지막 턴): 없음 · '현재 등록된 적합 상품 없음' 카드 표시

```
마당의 면적은 30㎡입니다. 주차장이라면 80mm 두께의 블록이 필요하며, 아래의 제품 중에서 선택하시면 좋을 것 같습니다. 지금 바로 관련 제품을 검색해 드리겠습니다. 잠시만 기다려 주세요.죄송합니다. 현재 등록된 상품 기준으로는 80mm 두께의 '보차도블록'과 '중하중 인터로킹' 제품이 없습니다. 발주처 설계도서나 시방서의 블록 규격을 확인하신 후, 별도로 문의 주시면 적합한 제품을 찾아드리겠습니다. 다른 질문이나 필요하신 정보가 있으면 언제든 말씀해 주세요.
```

합계: 통과 1 · 확인 필요 2 · 실패 0 (자동 점검은 보조 — '확인 필요'·'통과'도 답변 원문을 사람이 확인)
