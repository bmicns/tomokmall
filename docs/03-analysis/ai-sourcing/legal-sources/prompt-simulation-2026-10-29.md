## 1. 프롬프트 생성 분리 (`app/rag.php`)

- `rag_build_prompt(array $messages)` 를 새로 만들었다. 카테고리 감지, 상담 가이드, 사내 문서, 장소 판정, 법령 근거, 시스템 프롬프트를 묶어 반환하고 API 는 호출하지 않는다.
- `rag_process()` 는 이 결과를 그대로 OpenAI 에 보낸다. API 호출 루프·도구 처리·출처 추출은 그대로 두었다.
- 프롬프트 문장은 옮기기만 하고 바꾸지 않았다. 80T 문구 3개도 그대로다(테스트로 원문 일치 확인).
- 전후 동일성 확인 방법: 분리 전 코드로 7개 시나리오 × V21·V22 비활성/활성 = 14건의 OpenAI 요청 본문 전체(모델·도구 정의·메시지)를 캡처했다. 분리 후 같은 조건과 비교한 결과 **14/14 바이트 단위 일치**했다.
- 저장소 회귀 테스트: `tests/rag_prompt.test.php`(55건). 기준값은 `tests/fixtures/prompts/golden/` 이다.
- 이후 s3·s6 기준값만 아래 수정 F3 의 1줄씩 갱신했다.
- 시나리오별 프롬프트 확인(무료): `php scripts/testdb/dump-prompts.php [--with-public-road] [--out=폴더]`

## 5. 실제 GPT-4o 테스트 — 최소 시나리오와 비용

필요한 시나리오는 **핵심 3개**다(`consult-scenarios.php --core`). 각 시나리오에 면적 답변 턴을 붙여 추천 상품 두께까지 자동 점검한다.

| 시나리오 | 확인할 것(모델 행동) |
|---|---|
| 공공도로 차도 100mm | 100mm·KDS/KCS 출처 인용, 80T 비권장, 검색 시 spec_mm 100(제품 없음 안내) |
| 차량 진입 보도 80mm | 보도 지침 4t 이하 조건과 함께 80mm 인용, 차도 수치는 말하지 않음, 80T 제품 |
| 사유지 80T | 사내 80T 안내, 공공 출처를 인용하지 않음, 80T 제품 |

7개 전체는 필요 없다고 판단한다.
- 2(여러 턴)는 근거 결합이 자동 테스트로 확인됐다.
- 5·7 은 근거 범위가 자동 테스트로 확인됐다(공공 근거가 들어가지 않는 것이 결정적으로 보장됨).
- 6(불명확)은 V21·V22 활성화와 무관하다. 질문을 먼저 하는지만 보는 선택 항목이다.

- 요청 1회 입력은 약 4~6천 토큰이다(시스템 프롬프트 4.3~8천 자 + 도구 정의 2.3천 자 + 대화, 한글 1자 ≈ 1토큰으로 추정).
- 단가는 알고 있는 값($2.5/1M 입력, $10/1M 출력)으로 계산했다. 현재 단가는 OpenAI 가격표로 확인해야 한다.
