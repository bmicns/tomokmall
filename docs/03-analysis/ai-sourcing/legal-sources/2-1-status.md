# 2-1단계 — 기존 법령·기준 후보 39건 전수 검증 결과 (2026-10-28)

원문 확보 경로: 한국 공식 사이트(law.go.kr·kcsc.re.kr·standard.go.kr·molit.go.kr 등)는 이 작업 환경에서 모두 차단. 대체 경로로 **법제처 국가법령정보 Open API 원문을 그대로 옮긴 공개 미러**(GitHub `legalize-kr/legalize-kr` 법령, `legalize-kr/admrule-kr` 행정규칙, 둘 다 2026-10-27 갱신)를 사용했다.
- 미러 신뢰도 확인: 사용자가 공식 사이트에서 확인한 주차장법 시행규칙(국토교통부령 제1604호, 시행 2026-07-27, 제3조 일반형 2.5m×5.0m)과 미러의 메타데이터·조문 표가 **완전히 일치**.
- 그래도 공식 사이트 자체가 아니므로 확인 수준을 `api_text_verified`(법제처 원문 미러로 조문 확인)로 따로 표시한다. 운영 적용 전 공식 사이트 최종 대조 권장.
- 미러 HEAD는 '최신 공포판'이라 시행 예정판일 수 있음 → 사용한 조문은 모두 시행일이 지난 판인지 확인했고, 장애인등편의법 법률(시행 예정판)은 현재 시행판(2024-12-20 공포·2025-12-21 시행)과 제7조·제8조 문구가 같음을 대조.
- 별표·별지·첨부(점자블록 세부기준, 공공하수도 구조 기준, KDS·KCS 본문 등)는 미러에 **파일 링크만** 있고 내용이 없어 확보 불가. KS 원문은 유료·접속 차단.

## 5. 80T(차량용 블록 두께) 근거 조사 결과 — 기록만, 상담 문구는 변경하지 않음

- 「도로의 구조·시설 기준에 관한 규칙」 제29조제1항(포장)은 '적절한 재료와 두께'로만 규정하고 **두께 수치가 없다**(V04 — 상담 비활성).
- 블록 두께 수치가 있을 수 있는 KDS 44 50 25(차도용 블록포장설계)·KDS 34 60 10(보도포장)·KS F 4419 본문은 미확보.
- 따라서 현재 '차량이 올라가면 80mm 이상'·'80mm 이상 필수'·'일반 보도블록 사용 금지'는 **사내 기준**이며 공식 출처를 붙이지 않는다(로컬 테스트: 두께 질문에 법령 근거가 연결되지 않음을 확인).
