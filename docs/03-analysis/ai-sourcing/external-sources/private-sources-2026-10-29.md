## 4. 실행 (사용자 PC — 최소 작업)

수집은 끝났다(6장). **다시 수집하지 않고** 저장된 JSON 만 가져온다:

```
git pull origin claude/loving-gates-surk6e
# XAMPP 제어판에서 MySQL(MariaDB) Start → 새 Git Bash 창에서(이전 창의 DB_HOST 설정이 남지 않게)
unset DB_HOST DB_NAME DB_USER DB_PASS
DB_HOST=127.0.0.1 DB_NAME=tomokmall_test DB_USER=root DB_PASS= /c/xampp/php/php.exe scripts/external/import-crawled.php
```
- 결과: `data/external/crawl/quality.md`(출처별 원시·제외 사유·유효·중복·DB 저장·매칭) + `review.md`(승인 검토 목록·승인/제외 명령). 원본 JSON 은 바꾸지 않고 정리본은 `crawl/clean/` 에 따로.
- 외부 자료 테이블이 없는 예전 테스트 DB 면 추가형 테이블 2개(`database/20261029_external_products.sql`)만 만든다. 같은 JSON 을 다시 가져와도 행이 늘지 않는다.

- 2002 = DB 서버에 연결 자체가 안 됨. 수집 때 쓴 `DB_HOST='127.0.0.1;port=3308'`(MySQL 8.0 ZIP 시험용 포트)이 셸에 남아 있었고 그 포트의 MySQL 8.0 이 꺼져 있었던 것으로 판단(셸 환경 변수가 `.env.local` 보다 우선). 사용자 PC 에서 직접 확인하지는 못함.
- 해결: 새 DB 를 설치하지 않고 기존 XAMPP MariaDB(3306)의 `tomokmall_test` 사용 — 4장 명령.

| 작업 | MariaDB(XAMPP 10.4) | MySQL 8.0 필요 |
|---|---|---|
| 수집 JSON 가져오기·정리·중복 합침·매칭·보고서 | 가능 | |
| 외부 자료 테이블 자동 생성, 승인·제외, material_info(승인 자료 조회) | 가능 | |

- 검증(이 환경): MariaDB 10.4.32 컨테이너에 `setup-local-test-db.sh` 로 `tomokmall_test`(상품 1,452건)를 만들고 외부 자료 테이블을 지운 상태에서 `tests/external_import_crawled.test.php` 통과(테이블 자동 생성 포함), 승인 → material_info 흐름(`tests/external_crawl_sources.test.php`) 통과. MySQL 8.0 테스트 DB 에서도 같은 테스트 통과.

### 6-5. 출처별 재사용 범위 (sources.json `facts_if_clear` 조건 재확인)

수집 7곳(sunroad·enmcon·dhconc·gayasteel·toamconcrete·syccrt·dyhumepipe) 공통 — 수집 당시 robots.txt·이용약관 자동 확인 통과, 별도 이용 허락은 받지 않았다:

- 쓸 수 있는 것: 규격·재질·용도·KS 표기 같은 **사실 정보**, 짧은 **원문 문장**(200자 이하, 요약·보충 없이) + **출처 URL** 표기, 내부 참고(매칭·선택 도움말).
- 쓰지 않는 것: 이미지, 가격(수집하지 않음), 설명 전문 복제, 토목몰 판매 상품·판매가로 등록, 원문에 없는 특성·시공 적합성 추측.
- 상담 노출: 사람이 review.md 를 보고 승인한 행만, "제조사 자료에 따르면 … (출처)" 형식, 판매 상품·가격 아님 표시. 공식 기준과 다르면 공식 기준([L번호])을 따르고 해당 행은 제외.
- 제조사가 요청하면 즉시 삭제(`--reject`)하고, 장기적으로는 카탈로그 사용 허락(서면)을 받는다.
