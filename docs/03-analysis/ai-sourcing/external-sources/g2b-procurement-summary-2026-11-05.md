- `scripts/external/g2b_summary.php`(생성기)가 원본에서 다음 순서로 집계한다.
  1. 물품식별번호로 중복을 없앤다. 원본은 납품장소마다 같은 품목이 반복되며, 중복 제거 후 31,354개 품목·850개 업체다.
  2. 우리 취급 자재 세부품명 17종만 남긴다.
  3. 세부품명별 품목 수, 업체 수, 인증 표시 품목 수(KS·단체표준인증·우수조달·품질보증조달·환경표지), 쇼핑몰 등록일 범위를 센다.
- 결과 파일은 `app/procurement_summary.php`(약 11KB)이다. 가격·업체 이름·사업자등록번호는 넣지 않았다(테스트로 확인).
- AI 상담 연결:
  - `app/ai_tools.php` `ai_procurement_summary()` 가 질문·검색 결과의 자재 이름으로 해당 종류(최대 2종)를 고른다. `material_info`·`search_products` 결과의 `basics.procurement` 로 한 문장 요약(summary)과 함께 준다.
  - 프롬프트 규칙: summary 만 '조달청 품목 등록 내역에 따르면'으로 한 문장 쓴다. 다른 회사 품목의 집계이므로 **토목몰 상품이 KS 인증·조달 등록 제품이라고 말하지 않는다.**
  - 출처 카드: 답에 '조달'을 쓰면 '확인된 기본 정보(공공조달 등록 현황)' 카드에 자재 이름·품목 수·기준일과 공공데이터포털 링크가 붙는다.

## 3. 하지 않은 것과 이유

- **우리 상품과 품목 단위 매칭(같은 제품 확정)**: 우리 상품명·규격에 조달 업체 이름이 들어 있는 상품이 없다('콘크리트'·'솔루션' 같은 일반 낱말만 겹침). 같은 회사 제품이라고 확정할 수 없으면 다른 회사의 KS 표시를 우리 상품에 붙일 수 없어 하지 않았다.
- **가격(계약단가)**: 가져오지 않았다. 판매가와 섞일 위험이 있고, 가격 데이터 규칙(CLAUDE.md 12장)상 외부 가격을 운영 DB 에 넣지 않는다.

## 4. 다시 만들기 (자료를 새로 받았을 때)

```bash
php scripts/external/g2b_summary.php --file=<저장소 밖 허브 CSV> --md=<요약.md>
```

- 생성기는 저장소 안 원본을 거부한다. 결과는 `app/procurement_summary.php` 를 덮어쓴다(손으로 고치지 않음). 테스트: `php tests/g2b_summary.test.php`.
- 운영 반영: `app/procurement_summary.php`·`app/ai_tools.php`·`app/rag.php`·`public/assets/chat-ai.js` 코드 배포(보류 중) — DB 변경 없음. 파일이 없으면 이 기능만 빠지고 상담은 그대로 동작한다.
