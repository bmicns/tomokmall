## 1. 조사 한계

- **사이트를 직접 열지 못했습니다.** WebFetch는 모든 호스트에서 DNS 실패, 컨테이너 curl은 차단 상태였습니다. 그래서 크롤링은 하지 않았고, 사이트 본문·robots.txt·이용약관·API 문서도 열람하지 않았습니다.
- 근거는 **WebSearch(미국 기준 검색) 결과의 제목·URL과 검색 엔진 요약**뿐입니다. 요약은 틀릴 수 있으므로 표의 "있음" 항목도 직접 열람해 재확인해야 합니다.
- 국내 소규모 업체 사이트는 미국 검색에 잘 잡히지 않습니다. 검색에 안 나왔다고 해서 사이트가 없다는 뜻은 아닙니다.
- **robots.txt / 이용약관 / 공개 API는 모든 민간 후보에서 "확인 불가(직접 열람 필요)"** 입니다. 공공데이터포털 항목만 검색 요약에 이용조건이 일부 인용되었습니다.
- **"경북토건"은 찾지 못했습니다.** 따옴표 검색까지 해도 해당 상호의 사이트가 나오지 않았습니다. 가장 근접한 후보는 PC암거·사각수로관·맨홀블록 제조사인 **경북산업㈜(kcon.co.kr)** 이지만, 같은 회사인지는 확인되지 않았습니다.
- 저장소 내부 자료(`data/ktomok`, `data/dacity`, `scripts/scrape-*.mjs`)는 읽기만 했고 수정하지 않았습니다.
- 검색은 약 33회 했습니다.

### 주요 발견 사항

1. **ktomok.com과 dacity.kr는 상품 DB를 공유하는 관계로 보입니다.** 저장소에 수집된 이미지 URL을 보면, 두 사이트에서 같은 카테고리 ID와 같은 업로드 타임스탬프 디렉터리(예: 1련암거 `data/item/10/1010/1581996969/`)가 쓰입니다. 카테고리 번호도 겹칩니다(3340 체크무늬철판, 3425 인조화강블록 등). 같은 업체의 사이트인지, 플랫폼만 공유하는지, 자료를 제공받는 관계인지는 확인하지 못했습니다. 허락을 받을 때 **어느 쪽이 권리자인지** 먼저 확인해야 합니다.
2. **동아산업(dacity)은 나라장터 종합쇼핑몰에서도 판매합니다**(검색 요약: 암거·벤치플륨관·용배수관). 따라서 조달청 공공데이터로 일부 품목을 합법적으로 조회할 수 있을 가능성이 있습니다.
3. **기존 ktomok 수집 데이터에 개인정보가 섞여 있습니다.** 약 24행의 규격·설명 텍스트에 판매처 영업담당자의 실명·휴대전화·이메일이 들어 있습니다(값은 이 문서에 옮기지 않음). 운영 DB에 반영됐다면 상품 화면에 그대로 노출될 수 있습니다. 정리하자는 **제안**이며, 데이터 수정은 승인이 필요합니다.
4. 기존 ktomok 상품의 `image_url`은 ktomok.com 서버 이미지를 직접 참조(핫링크)합니다.

### 위험 요약 (일반론, 법률 자문 아님)

- **가격·규격 같은 사실 자체**는 저작물이 아닙니다. 하지만 **상품 사진·설명문·도면**은 창작성이 있으면 저작물로 보호될 수 있습니다.
- **저작권법 제93조(데이터베이스제작자의 권리)**: DB의 전부 또는 상당한 부분을 복제·배포·전송하면 권리 침해가 될 수 있습니다. 개별적으로는 상당하지 않은 부분이라도 **반복적·체계적으로 복제**해서 DB의 통상적 이용과 충돌하거나 제작자 이익을 부당하게 해치면 상당한 부분으로 봅니다(제93조제2항). 쇼핑몰 전체 상품·단가를 정기적으로 긁어 오는 방식이 여기에 해당할 수 있습니다.
- **부정경쟁방지법 제2조제1호**: 데이터 부정사용 행위(카목, 2022년 시행)와, 타인이 상당한 투자·노력으로 만든 성과를 공정한 상거래 관행에 반해 무단 사용하는 행위(파목)가 있습니다. **같은 시장의 경쟁몰 단가·상품 DB를 그대로 가져와 판매에 쓰는 것**은 위험이 큰 유형입니다. 조문 기호는 개정에 따라 바뀔 수 있으니 최신 법령을 확인하세요.
- **개인정보보호법**: 수집 텍스트에 섞인 개인 연락처는 목적 외 이용·노출 위험이 있습니다.
- 사이트 이용약관에 크롤링·자동수집 금지 조항이 있으면 계약 위반 문제가 별도로 생길 수 있습니다(약관 미확인).
