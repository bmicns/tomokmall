# 외부 건축자재 데이터 수집·정규화·매칭 — 1차 구현 (2026-10-29)

목표: 초보 고객이 **추가 검색 없이** 상담 카드만 보고 자재를 고를 수 있게, 허락된 외부 자료로 상품 설명(고르는 기준)을 보강한다.
외부 자료를 토목몰 판매 상품·가격으로 등록하지 않는다(가격은 참고가로만 보관, products 는 바꾸지 않음).

## 1. 15곳 수집 가능성 재확인

- 이번 작업 환경(클라우드)은 네트워크 정책으로 **외부 사이트·공공데이터포털 접속이 모두 차단**됐다(ktomok.com, data.go.kr 등 — 연결 거부·DNS 실패). 그래서 사이트를 직접 다시 열지 못했다.
- 대신 사용자 PC에서 한 번에 재확인하는 도구를 만들었다: `php scripts/external/check-sources.php --md=docs/03-analysis/ai-sourcing/external-sources/source-check.md`
  - 출처마다 `robots.txt` 판정(전체 금지·상품 경로 금지·금지 없음)과 홈페이지의 이용약관·저작권·개인정보 링크를 표로 남긴다. 상품 페이지는 읽지 않는다(도메인당 2회, 1초 간격).
  - robots.txt 에 금지가 없어도 **약관·DB 제작자 권리·제휴 여부는 사람이 판단**한다.

| 파일 | 내용 |

| `scripts/external/import.php` | 출처 권한 확인 → 정규화 → 중복 제거 → 우리 상품 매칭 후보 → 검증 구역 저장 → 보고서. `--confirm=외부ID:상품ID` 로 사람이 확정 |

| `app/ai_tools.php`, `public/assets/chat-ai.js` | 상담 카드에 `guide`(고르는 기준)·상세 링크·치수만 표시한 규격 |

안전장치: blocked 거부 · pending 은 `--dry-run` 만 · 이용 조건 있는 출처는 `--license-checked` 필수 · 저장은 `DB_NAME=*_test` 만 · 외부 가격은 `ref_price`(참고가) · 개인 연락처는 저장 전 제거 · 매칭은 후보(candidate)까지 자동, 상담 카드에는 **사람이 확정(confirmed)한 것만** 출처와 함께 표시.

매칭 점수(0~100): 종류(다르면 0점) + 이름(같으면 30, 모델 표기 NS-02/NS-03·AN형/DN형이 다르면 감점) + 규격 문자열 + 치수(두께·관경·가로·세로·셋째 치수, 다르면 2배 감점) + 재질·투수 여부. 80 이상 '유력', 50~79 '검토'.

## 3. 시범 결과 (실제 신규 수집 0건)

네트워크 차단으로 새로 수집한 외부 데이터는 **0건**이다. 대신 저장소에 이미 있는 수집분으로 정규화·매칭을 시험했다(허락 전 출처라 저장하지 않고 분석만).

| 시험 | 결과 |
|---|---|
| dacity 10건 → 우리 상품 매칭(`--dry-run`) | 10건 모두 유력(95~100점), 1순위가 같은 규격(0.8×0.8×2.0·130T 등)의 1련암거 |
| ktomok 1,452건 → 같은 상품 맞히기(정확도 상한 측정) | 1순위 정답 1,442건(99.3%), 2~3순위 10건, 후보 없음 0. 처음 67.9% → 모델 표기·규격 문자열·셋째 치수 비교 추가로 개선 |
| 중복 키 | ktomok 1,452행 중 8건이 같은 상품으로 합쳐짐 |
| 통합 테스트(임시 '[테스트]' CSV, 끝나면 삭제) | CP949·탭 CSV 인식, 중복 1건 합침, 연락처 제거, 재실행 시 갱신, candidate 는 카드에 안 보이고 confirmed 만 '외부 자료: 제조사 · KS (출처)'로 표시, products 건수·판매가 합계 불변 |

같은 출처끼리 맞힌 99.3% 는 상한이다. 다른 출처(조달청 품명·규격 표기)는 표기가 달라 낮아질 수 있으므로, 첫 공공데이터 파일로 '검토' 비율을 보고 규칙을 보강한다.

## 4. 상담에서 쓰는 방식

1. 검색 결과 카드마다 **고르는 기준**(최대 4줄)을 붙인다 — 상품 규격에서 읽은 것만: 두께(사내 80T 기준), 투수·불투수, 재질 정의(인조화강·점토·잔디블록), 그레이팅 하중 등급(프롬프트의 기존 등급 설명), 유공관·이중벽관, ㎡ 단위. 성능·강도 수치는 만들지 않는다.
2. 사람이 확정한 외부 자료가 있으면 '외부 자료: 제조사 · KS 표기 (출처 조달청 …)' 한 줄을 더한다. 외부 가격은 쓰지 않는다.
3. 모델에는 "guide 에 있는 기준 하나를 골라 쉬운 말로, guide 에 없는 성능·수치는 덧붙이지 않는다" 규칙 1줄.
4. 다음 단계(제안): 확정 외부 자료가 쌓이면 상품 상세 페이지에도 같은 '고르는 기준'을 표시, 조달청 물품분류번호로 카테고리 표준화.
