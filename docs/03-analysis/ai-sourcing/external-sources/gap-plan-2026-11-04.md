## 2. 지난 수집에서 배운 점 (2026-10-29 결과 재확인)

- 제조사 홈페이지는 규격표는 많지만 **설명 문장이 적다**: 8곳 원시 1,301행 → 설명 문장 88개 → 승인 후보 28개(메뉴·제목·홍보 문구가 대부분).
- 실제 GPT-4o 상담에서 주어 없는 문장('기존 벤치플룸관에 비해 대형')을 다른 제품 설명으로 뒤집은 오답이 나왔다 → **문장 단위 사람 승인**은 계속 필요.
- 규격·용도·시공 주의가 잘 정리된 곳은 **카탈로그 PDF** — 저작물이라 제조사 허락을 받아야 쓸 수 있다(`permission-request-template.md`).
- 이번 웹 검색으로 공백 자재(PE관·보강토·맨홀·경계석) 제조사 공식 도메인을 찾으려 했으나 구인·기업DB 사이트만 나와 **도메인을 확정하지 못했다** → 추측한 도메인은 등록부에 넣지 않았다.

## 3. 다음 수집 계획 (우선순위)

| 순서 | 대상 | 방법 | 기대 효과 |
|---|---|---|---|
| A | 동아산업(dacity) — 수로관·암거·벤치플륨관 | **이용 허락 요청**(템플릿) → 허락되면 `sources.json` 에서 `pending → facts_if_clear` 로 바꾸고 수집 | 1순위 공백(213개) 직접 해소. 우리 상품 출처와 같은 제조사 |
| B | 이미 수집한 대한산업(283행)·토암·엔엠콘 | 사용자 PC 의 `data/external/crawl/` 결과로 `approve-crawled.php` 검토 — 설명 문장이 없는 출처는 규격만 '참고 자료' 줄로 쓸지 결정 | 맨홀 뚜껑·트렌치·점토블록에 등록 규격 근거 |
| C | PE관·맨홀·보강토·경계석 제조사 | **거래하시는 제조사 이름·홈페이지를 알려 주시면** 등록부에 추가(robots·약관 자동 확인 후 사실 정보만) | 2~5순위 공백 |
| D | 88콘크리트·경북산업 카탈로그 | 허락 요청(기존 보류 출처) | 경계석·맨홀 |
| E | 조달청 나라장터 품목정보(공공데이터) | 활용신청·키 발급 후 `g2b-api.php --discover`(기존 도구) | 제조사·KS 인증·규격 대조(가격은 참고가로만) |

수집 실행은 두 가지 중 하나:

1. **사용자 PC에서 실행**(지난번과 같음, 가장 확실): 새 출처가 등록되면
   `php scripts/external/crawl-sources.php --only=<출처키,…> --import` → `data/external/crawl/report.md`·`review.md` 공유
2. **클라우드 환경 네트워크 허용**: 세션 제목줄의 클라우드 환경 메뉴 → Edit → Network access → Allowed domains 에 수집할 제조사 도메인 추가(‘Allow package managers’ 는 체크 유지). 안내: https://code.claude.com/docs/en/cloud-environments#network-access
   - 제한: 이 환경은 **https 사이트만** 통과(제조사 다수가 http 전용 — 지난 조사) → http 전용 사이트는 PC 실행이 필요.
   - 법령 공식 API 대조용으로 `www.law.go.kr` 를 허용하면 V28~V35 공식 대조를 이 환경에서도 할 수 있다(인증값 `LAW_API_OC` 를 환경 변수로 넣어야 함 — 값은 채팅에 쓰지 말 것).
