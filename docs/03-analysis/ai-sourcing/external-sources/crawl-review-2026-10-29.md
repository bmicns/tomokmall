※ 사용자 메모의 '5번 확인 필요'는 파일상 **2번**이다(5번은 자동 점검 통과, 다만 위 단정 표현 문제).

### 9-4. 매칭 후보 35건(대한산업 29·토암 6) 판단 — 확정 0 권장

- 그레이팅: 대한산업 '주철 / 스틸그레이팅' ↔ 우리 'EX메탈망그레이팅'·'중하중그레이팅맨홀' — 재질·하중 구분이 달라 **다른 상품 가능성**(이제 '이름 주철·스틸≠메탈망'으로 표시).
- 암거: 'PC 암거 2.5 x 2.0'(길이 1000, 1련/2련 표기 없음) ↔ 우리 2련암거(길이 2.0m) — 길이 다름, 련 수 확인 필요. 1련 0.8·1.0 은 내공 같지만 길이 1.0m vs 2.0m.
- 수로관: '원형사각수로관(RDG형)몰드' 는 거푸집 — **다른 상품**(이제 '몰드 여부 다름' 표시).
- 경계석 120 ↔ 150*150*150 — 다른 규격. 토암 '주메뉴 그레이팅·집수정' 은 행 이름이 메뉴 글자로 오염.
- 결론: 점수 50~66 은 종류 일치 + 일부 규격 유사 수준. 지금 확정할 쌍은 없다(확정 0 → 상품 카드 영향 없음).
