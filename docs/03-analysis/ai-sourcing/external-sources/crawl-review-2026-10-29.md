## 3. 토목몰 상품 매칭 — 정확도와 잘못된 매칭 가능성

| 판정 | 건수 | 해석 |

- 23건의 실제 쌍은 이번 두 파일에 없어 **정확도를 판정하지 못했다**. `approve-crawled.php` 보고서가 23건을 외부 행·우리 상품 나란히, 다른 점(두께·관경·폭·길이·높이·재질·모델)과 함께 '같은 상품 가능 / 확인 필요 / 다른 상품 가능성' 으로 보여 준다. 확정은 사람이 `import.php --confirm=외부ID:상품ID`.

## 7. 승인 절차 (자동 승인 없음)

1. `php scripts/external/approve-crawled.php` → `data/external/crawl/approval-candidates.md`: 출처별 승인 후보 ✅ / 보류 ⏸(사유), 행 점검 ⚠, 매칭 후보 비교. DB 는 바꾸지 않는다.
2. 사람이 읽고 출처별로: `php scripts/external/approve-crawled.php --approve=gayasteel --exclude='문장 일부'`
   - 승인 후보 문장이 있고 ⚠ 가 없는 행만 approved, 문장은 후보만 남기고 보류 문장은 `facts_held`(사유)로 옮김.
   - 허락 필요 출처는 거부, `import.php --approve-source` 로 문장 검토를 건너뛰는 것도 거부.
   - 다시 가져와도(import-crawled) 승인 행의 문장은 덮어쓰지 않음.
