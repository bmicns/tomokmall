# AI 상담 운영 테스트 문구 (2026-11-11 배포 기준)

> 대상: 운영 AI 상담(`/chat.php`). 기준 코드 main `896a1bf`(배포 후), 운영 DB 2026-11-11(분류 설명 반영).
> 기대 결과는 운영 DB 읽기 전용 조회로 확인한 실제 자료(활성 법령 근거 20건, 승인 제조사 자료 14건, 등록 상품)로 적었다.
> **시나리오마다 '새 상담'으로 시작**한다(앞 대화의 조건이 이어짐). 표의 질문은 위에서부터 순서대로 입력한다.
> 실제 GPT 답이라 문장은 매번 다르다 — '통과 기준'(✓)과 '나오면 안 됨'(✗)으로 판정한다. 예상과 다르면 질문 순서와 답을 복사해 주면 운영 상담 기록(읽기 전용)으로 원인을 찾는다.
> 질문마다 OpenAI 유료 호출이 생기고 상담 기록(`chat_logs`)에 남는다.
