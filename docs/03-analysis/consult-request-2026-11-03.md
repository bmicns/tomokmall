- 상담 키는 이 브라우저에서 연 상담만 연결(다른 사람 상담 연결 차단). 같은 세션 10분 3건 제한.
- 오류 응답은 HTTP 200 + `ok:false`(닷홈이 4xx 본문을 바꾸는 문제 — `remaining-work-2026-10-30.md` A-1).

## 4. 문자 설정 (`/app/.env`, 값은 커밋·채팅 금지)

```dotenv
SMS_PROVIDER=solapi        # 또는 aligo
SMS_API_KEY=
SMS_API_SECRET=            # solapi 만
SMS_USER_ID=               # aligo 만
SMS_SENDER=                # 발송 업체에 사전 등록한 발신번호
SMS_SENDER_NAME=비엠아이토목건축자재   # 선택(관리자 화면 표시·LMS 제목)
SMS_TEST_MODE=             # aligo 만, Y 면 실제 발송 없이 접수 확인
```

- 솔라피: `POST https://api.solapi.com/messages/v4/send`, HMAC-SHA256 인증, 성공 `statusCode 2000`.
- 알리고: `POST https://apis.aligo.in/send/`, 성공 `result_code 1`. **발송 서버 IP 등록이 필요**(닷홈 서버 IP).
- 발신번호는 사전 등록(번호 도용 방지 제도)이 끝나야 발송된다.
