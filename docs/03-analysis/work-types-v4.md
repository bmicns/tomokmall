# 작업 유형 v4 — 실제 수행 작업과 대표 자재 (검토용)

- 기초 자료: 운영 DB 카테고리 245개(Q3)·상품 요약(Q5), v3 작업 목적 분류안(20개)
- 대표 자재 선정 원칙: 작업당 **최대 10개**(추가 페이지 없음). 해당 작업의 핵심 본체 자재를 우선하고, 시공에 꼭 필요한 주요 부속을 함께 선정. 같은 계열의 형식·재질 변형은 대표 1~2개로 묶음. 시공 장비 성격(인양 집게 등)은 제외
- **근거 구분**: 운영 DB에 작업별 실제 사용 빈도 데이터가 없고(견적·주문·검색 집계는 사용하지 않기로 함), 모든 선정은 **일반적인 토목·건축 시공 관행에 근거한 판단**임
- 상품 수·활성 상품 수가 적다는 이유로 제외한 자재 없음
- PE망(203)·제조용 몰드(215~229) 16개: **대표 자재 선정 제외(확정)** — 20개 작업 전부에 적용. 운영 DB 삭제·비활성화 없음, 기존 카테고리 메뉴·상품 검색 접근은 그대로
- 대표 자재로 선정되지 않은 카테고리도 기존 탐색(카테고리 메뉴·검색)에서 그대로 접근 가능 — 메인 작업 패널에만 표시되지 않음
- 코드·DB·UI 변경 없음 / main 병합·운영 배포 없음
