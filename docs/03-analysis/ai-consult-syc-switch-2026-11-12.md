# AI 상담 — 상용콘크리트 상품 전환 대응 (2026-11-12)

> 2026-11-12 운영 고객 화면이 케이토목 → 상용콘크리트(B 방식: 상용콘크리트를 `products` 에 반영, 케이토목 숨김)로 바뀌었다([syc-products.md](../02-design/syc-products.md) 10장).
> AI 상담은 같은 `products`·`categories` 를 쓰므로 코드 변경 없이 상용콘크리트를 찾지만, 케이토목 기준으로 다듬은 판단이 맞지 않는 곳이 생겼다.
> 운영 DB 는 읽기 전용 집계만 했다(가격·회원 칸 값은 보지 않음 — 가격 0원 여부만 COUNT). 운영 DB·서버 변경 없음.

## 1. 운영 상품 구성(전환 후, 읽기 전용 집계)

- 보이는 상품 704개(상용콘크리트 테스트 데이터 — 카탈로그 판독본 + 임시값), **전 상품 판매가 0원(견적문의)**.
- 대분류: 철근콘크리트(수로관·플륨관·측구수로관·암거·맨홀·흄관/VR관), 콘크리트(보도블록·옹벽·경계석), PE/PVC(받이·집수정), 스틸(맨홀 뚜껑·보호틀·파형강관·용접철망·볼라드).
- **사이트에 상품이 없는 품목**: 스틸 그레이팅, PE·PVC 배수관(이중벽관·삼중벽관·VG·HDPE·THP·고압유공관·ELP). 상용콘크리트 카탈로그에 분류는 있으나 **규격표가 없어 테스트 데이터에서 상품을 만들지 않은 11개 분류**다([syc-products.md](../02-design/syc-products.md) 4장) — 취급하지 않는 품목이 아니다. 그레이팅은 측구수로관·빗물받이·사각맨홀·원심력수로관 등 80개 상품의 상세 치수에 옵션 규격으로 들어 있다.
- 상품 규격은 케이토목과 같은 모양('규격: … | 중량 | 단위')이고 치수 칸(폭 W·길이 L 등)이 채워져 있어 폭·길이 판정은 그대로 동작한다. 판매 단위 면적 표기는 'm²'(위첨자).

## 2. 실제 AI 검색으로 확인한 문제(로컬 운영 동일 구성 DB)

| 질문 | 전환 후 결과(수정 전) | 원인 |
|---|---|---|
| 그레이팅 수로용 폭 500 | '그레이팅 높이조절용 측구수로관'·'측구수로관'을 덮개처럼 추천 | 덮개 상품이 없어 이름에 '그레이팅'이 있는 수로관 본체가 걸림 |
| 보도블록 30㎡ | 수량 없음 | 단위 'm²'(위첨자)를 면적 단위로 못 알아봄 |
| 투수블록 | 녹지경계·게다·장대 블록 | '투수'가 분류 이름('인조화강블록 투수/불투수')에만 있음 |
| U형 수로관 | 안내에 'U형 볼라드' | 'U형 플륨'이 같은 종류임을 모름 |
| PE 배수관·이중벽관 | 파형강관 등 / 0건 일반 안내 | 판매하지 않는 품목이라는 안내 없음 |
| 트렌치 폭 150 | 소켓(부속)이 본품 앞 | 부속 제외가 케이토목 이름(집게·몰드) 기준 |
| 전 품목 | 예상 자재비 없음, GPT 가 '가장 저렴' 비교 가능 | 전 상품 0원 |

## 3. 수정(서버 코드, 2026-11-12)

| 파일 | 내용 |

| `app/ai_tools.php` | ① 덮개 검색(그레이팅·덮개·뚜껑·커버)은 덮개 상품만, 없으면 표 없이 '○○(덮개) 단품은 사이트에 아직 등록되지 않았습니다. 견적요청하기로 문의… + 그레이팅 옵션이 있는 수로관'(`not_carried`, 2026-11-13 문구) ② 'm²' → ㎡ ③ 검색어가 모두 분류 이름(상위 포함)에 있는 분류의 상품을 후보로 넣고 먼저, 그런 상품이 있으면 한 낱말로만 걸린 다른 품목은 뺌(`ai_category_match_rows`) ④ 품목 이름 낱말이 판매 상품·분류 이름에 전혀 없으면 '○○은(는) 사이트에 아직 등록된 제품이 없습니다. 견적요청하기로 문의…'(`ai_not_carried_note`) ⑤ 부속(소켓·조절링·인상링·연결구)은 묻지 않으면 본품만 ⑥ 표가 모두 0원이면 `price_inquiry`·`price_note`(GPT 용: 금액 비교 금지, 수량 + 견적 요청) |

실제 GPT 답은 미검증(키 없음) — 배포 후 운영에서 [테스트 문구](ai-consult-test-questions-2026-11-11.md) 0장으로 확인.

## 4. 남은 점·결정 필요

1. **(결정 완료 2026-11-13) 그레이팅·PE 배수관 문의**: '판매하지 않음'이 아니라 '사이트에 아직 등록되지 않음 + 견적요청하기로 문의'로 안내(덮개 검색이면 그레이팅 옵션이 있는 수로관도 함께). 실제 상품이 일괄 등록·반영되면 AI 는 코드 변경 없이 그 상품을 찾는다.
2. **(진행 2026-11-13) 상담 가이드 문구**: 상용콘크리트 모드에서는 새 가이드 `grating_syc`·`pe_pipe_syc`(`database/20261113_consult_guide_syc.sql`, 새 행 2개 — 기존 케이토목 가이드는 그대로)를 먼저 읽고, 프롬프트의 그레이팅 하중 3단계(그레이팅수로용·중하중·안전중하중)·'그레이팅 수로용 중하중' 검색어 예시 대신 '덮개 단품 미등록·하중 등급 자료 없음(등급 이름·T-25 말하지 않음)·그레이팅 규격이 표기된 수로관·집수정' 규칙을 쓴다(`app/rag.php` `rag_catalog_is_syc`·`rag_grating_syc_prompt`). 케이토목 모드 프롬프트는 바뀌지 않음(골든 프롬프트 그대로). T-25 근거 검증: [heavy-grating-t25-check-2026-11-13.md](heavy-grating-t25-check-2026-11-13.md).
3. **가격**: 전 상품 0원이라 수량만 안내하고 금액은 견적 요청. 실제 가격이 들어오면 기존 예상 자재비·비교가 자동으로 다시 동작한다.
4. **하중**: 상용콘크리트 맨홀 뚜껑 규격에 차도/보도 표기가 없어 차량 통행 질문에는 모두 '하중 확인 필요'. 실제 데이터에 하중 등급이 오면 반영 가능.
5. **차량용 포장 80T**: 80T 블록은 I₂·U 블록 일부와 잔디블록 계열뿐 — 블록 질문의 추천 폭이 좁다.
6. **제조사 참고 자료**: 승인 자료 14건 중 가야스틸 5건은 그레이팅 자료다. 판매 상품이 없어도 일반 설명으로 쓰일 수 있다(출처는 하단 표시).
