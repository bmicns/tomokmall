# 규격 이름표 확인 목록 (category_spec_axes)

> 만든 날: 2026-11-06 · 원본: 운영 DB 읽기 전용 조회(활성 상품, `규격:` 형식만). 가격·개인정보 없음.
> 쓰는 법: 소분류(또는 같은 표기를 쓰는 중분류)마다 **앞 숫자가 차례로 무엇인지**(이름·약자·단위)를 적어 주면 `category_spec_axes` 행으로 넣는다.
> 이름을 모르는 값은 추측해 넣지 않는다 — 이 목록의 빈칸이 확인이 필요한 곳이다. 설계: [`docs/02-design/spec-axes.md`](../02-design/spec-axes.md)

- **2026-11-06 갱신**: 원본 사이트 표 머리글 기준으로 110개 카테고리 이름표를 정함 → [`spec-axes-site-structures.md`](spec-axes-site-structures.md) (이 목록보다 우선). 칸도 나눔(내경 `dim_d_i`·외경 `dim_d_o`·하부폭/뒷폭/상부폭·깊이 `dim_depth`).
- **약자 규칙**: 약자 = 값을 담는 칸의 글자 — 가로·폭 W(`dim_w`), 길이 L(`dim_l`)·세로 V(`dim_v`, 2026-11-09 나눔), 높이 H(`dim_h`), 두께 T(`dim_t`), 내경 D(`dim_d`). 한 카테고리에 세로와 길이가 함께 있으면 그때 따로 정한다.
- **앞 숫자**: 규격 맨 앞에서 `*`·`_` 로 이어진 숫자 묶음(규칙이 읽는 부분)과 개수. `D`=직경 표시, `T`=두께, `H`=높이, `M`=미터.
- **확정**: 이름표를 넣은 7개(사용자 확인). 나머지는 이름 확인 전이라 목록 화면이 지금처럼 규격 원문을 쓴다.
- 같은 소분류 안에서 표기가 섞인 경우(예: 앞 숫자 개수가 다름)는 규칙이 읽지 못한 상품만 `spec-axes-fill.php report` 의 "못 읽음"으로 나온다.
