- `높이(I-BAR)` 는 높이로, `_파형` 은 숫자가 아닌 옵션 자리(예: `_0RS`)로, `외경(폭X길이X높이)`·`내경(폭X깊이X길이)` 처럼 묶인 것은 안쪽 이름으로 읽음.
- m 표기: 개거 폭·높이·길이, 원형사각수로관류 길이(2M), 그리드 폭·길이(2m·50m). 인장강도는 t/m 그대로. 그 밖에는 mm.
- 옵션 화면 표시: 밑줄 → 슬래시, 통째로 괄호에 싸인 조각은 괄호를 뗌(`(B)` → `B`, `(SA)_곡선` → `SA/곡선`). 저장값은 원문 그대로.
