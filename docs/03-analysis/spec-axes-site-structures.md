- `높이(I-BAR)` 는 높이로, `_파형` 은 숫자가 아닌 옵션 자리(예: `_0RS`)로, `외경(폭X길이X높이)`·`내경(폭X깊이X길이)` 처럼 묶인 것은 안쪽 이름으로 읽음.
