# 페이퍼로지(Paperlogy) 글꼴 파일

`public/assets/fonts.css`가 이 폴더의 파일을 먼저 읽고, 없으면 jsdelivr CDN을 사용한다.
아래 7개 파일을 이 폴더에 넣으면 외부 CDN 없이 사이트 내부에서 제공된다(파일명 그대로).

- Paperlogy-2ExtraLight.woff2 (200)
- Paperlogy-3Light.woff2 (300)
- Paperlogy-4Regular.woff2 (400)
- Paperlogy-5Medium.woff2 (500)
- Paperlogy-6SemiBold.woff2 (600)
- Paperlogy-7Bold.woff2 (700)
- Paperlogy-8ExtraBold.woff2 (800)

받는 곳: 현재 CDN 주소 `https://cdn.jsdelivr.net/gh/projectnoonnu/2408-3@1.0/<파일명>`
(또는 눈누 noonnu.cc 페이퍼로지 페이지). 페이퍼로지는 SIL OFL 라이선스로 웹사이트 자체 호스팅이 허용된다.
